03 Projects

AI · Featured

bag-triage-mcp

AI root-cause agent for baggage operations

An MCP (Model Context Protocol) server that turns baggage troubleshooting into a conversation. Give the agent a bag tag or BagUniqueId, ask "what happened?", and it runs CloudWatch Logs Insights queries across the event timeline, reconstructs the bag's persistence history across services, and explains exactly where a reroute or lookup went wrong. The same tools cover passenger and flight events, so one chat covers the whole pipeline.

  • Replaced manual multi-service log hunting with a single prompt
  • Tools expose Logs Insights queries scoped to the bag's timeline
  • First stop for support, on-call and QA during incidents
