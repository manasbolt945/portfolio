03 Work that matches the role

AI · Workflow logic

bag-triage-mcp

Python MCP server that turns incident triage into a conversation

Built with FastMCP and boto3. Give the agent a bag tag, ask "what happened?", and its tools run CloudWatch Logs Insights queries across the event timeline, reconstruct the bag's persistence history across services, and explain exactly where a reroute or lookup went wrong. The same tools cover passenger and flight events, so one chat covers the whole pipeline.

  • Replaced hours of manual multi-service log hunting with a single prompt
  • Field lessons became reusable tools: every incident pattern is a typed tool with a scoped query
